## 标题写法

实测标题都很短，4~18 字，口语化，**不带句号**：

- 极简：`连接打印机` / `打印机异常` / `打印机无法打印`
- 带对象：`用户电脑安装打印机` / `资产打印机连接` / `部门打印机硒鼓碳粉用尽`
- 带位置：`省区安保监察部黑色&彩色打印机更换硒鼓`
- 带现象：`打印机打印空白纸` / `文档打印提示打印机卡纸` / `打印机不能自动打印双面`
- 别写成「关于打印机无法打印问题的处理」这种公文腔

## 拆分粒度

设备类不是按模块拆，是**按设备 / 按动作拆**：

- 一台电脑配一次打印机 = 一单
- 换一次硒鼓 = 一单
- 同一个故障反复处理，按次拆

证据：王客 2026-10-21 一天 22 单，全是「用户电脑安装系统，安装打印机」；
王心帅 2026-08-25 一天 18 单，全是「文档打印提示打印机卡纸」。

但如果一次上门处理了 5 台电脑，也可以只记一单（写成「5 台电脑安装打印机」）——
看你想体现的工作量粒度。
